# Avatar pictures

Replace the placeholder files with your own square pictures (≥200×200 px works
best — they are displayed as circles):

```
avatar-1.png  avatar-2.png  …  avatar-10.png
```

Keep the exact names; refresh the browser and they appear everywhere players
are rendered. If a file is missing or broken, that player automatically falls
back to a colored letter disc — nothing else to configure.
